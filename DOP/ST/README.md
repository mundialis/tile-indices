This folder contains a tileindex for DOP tiles (with size of 2000 x 2000 m) of Sachsen-Anhalt. It was created by using a python script.

Tile index:
- `st_dop_tindex_proj.gpkg.gz`
- contains one poylgon for every tile
- ID of the tile stored in attribute "item_id"

Download script:
- `ST_DOP_tindex.py`
- gets for later download relevant data (item_id) from geojson
- gets polygon coordinates from geojson
